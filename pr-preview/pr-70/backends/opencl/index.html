OpenCL

Vendor-neutral array and kernel programming for any device with an OpenCL driver, including CPUs through PoCL.

OpenCL.jl documentation OpenCL.jl

OpenCL.jl makes it possible to program any device with an OpenCL driver from Julia: GPUs from NVIDIA, AMD and Intel, but also CPUs, using PoCL or Intel’s CPU runtime. It offers the same programming model as the other JuliaGPU back-ends: a CLArray type for array programming, and kernels written in Julia and launched with @opencl. These kernels are compiled to SPIR-V, and on drivers that can’t load SPIR-V, such as NVIDIA’s, translated to OpenCL C. Traditional kernels written in OpenCL C are supported as well.

With PoCL, OpenCL.jl can execute GPU-style Julia code on the CPU, which is useful for testing GPU code on machines without a GPU, and as a CPU back-end for portable libraries.

Installation

OpenCL.jl is installed with Julia’s package manager. It needs an OpenCL driver, which can be installed system-wide (e.g., with the GPU vendor’s driver package), or added as a Julia package: pocl_jll provides PoCL on all platforms, and intel_opencl_rt_jll Intel’s CPU runtime on x86_64 Linux and Windows. These need to be loaded before OpenCL.jl is first used, because the list of drivers is only read once. OpenCL.jl supports Julia 1.10 and later on Linux, macOS and Windows, and is tested with PoCL, Intel’s CPU runtime and NVIDIA’s OpenCL driver; what works on other drivers depends on the features they support. Array programming

The easiest way to use a device is through CLArray. Operations on these arrays, such as broadcasting and reductions, are executed by the OpenCL device:

julia> a = CLArray(Float32[1, 2, 3, 4])
4-element CLArray{Float32, 1, OpenCL.cl.UnifiedDeviceMemory}:
 1.0
 2.0
 3.0
 4.0

julia> b = a .^ 2 .+ 1f0
4-element CLArray{Float32, 1, OpenCL.cl.UnifiedDeviceMemory}:
  2.0
  5.0
 10.0
 17.0

julia> sum(b)
34.0f0

By default, OpenCL.jl uses the first device of the first platform; another one can be selected with cl.platform! and cl.device!, e.g., cl.platform!("NVIDIA").

Kernel programming

Kernels can be written in Julia and launched with @opencl, specifying the total number of work-items with global_size. Here on an NVIDIA GPU, whose driver does not accept SPIR-V, so OpenCL.jl translates the kernel to OpenCL C first:

julia> using OpenCL

julia> cl.platform!("NVIDIA");

julia> function vadd(a, b, c)
           i = get_global_id()
           @inbounds c[i] = a[i] + b[i]
           return
       end
vadd (generic function with 1 method)

julia> a = CLArray(rand(Float32, 1024)); b = CLArray(rand(Float32, 1024)); c = similar(a);

julia> @opencl global_size=length(c) vadd(a, b, c);
┌ Warning: Device 'NVIDIA RTX 6000 Ada Generation' lacks IL support; using OpenCL C translation.
└ @ OpenCL ~/.julia/packages/OpenCL/DrrmN/src/compiler/compilation.jl:316

julia> Array(c) ≈ Array(a) + Array(b)
true

For kernels that are portable across GPU back-ends, use KernelAbstractions.jl with OpenCLBackend(). Existing kernels written in OpenCL C can be used too, as shown in the documentation.
