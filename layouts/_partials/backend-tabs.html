Which one is shown is decided page-wide by the radio buttons of the backend-picker partial; until the visitor picks one, the group shows its first example. Takes a dict with: - variants: a list of dicts with the back-end `name` (from `params.backends`) and the rendered `html`; - rotate: optionally, the number of seconds after which to move on to the next example until the visitor picks one. Every tab and example then runs the same CSS animation, shifted by its position; its keyframes depend on the number of examples, so they are generated here. */ -}} {{- $variants := .variants }} {{- $n := len $variants }} {{- $rotate := .rotate | default 0 }} {{- range $variants }} {{- if not (in site.Params.backends .name) }} {{- errorf "unknown back-end %q; add it to params.backends in hugo.toml" .name }} {{- end }} {{- end }} {{- if $rotate }} {{- $slot := printf "%.4f" (div 100.0 $n) }} {{- end }}
{{- range $i, $v := $variants }} {{- end }}

{{- end }}
